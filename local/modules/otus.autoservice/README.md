# Модуль `otus.autoservice`

Каркас локального D7-модуля для автоматизации автосервиса в CRM Битрикс24.

Текущая версия: `0.1.0`.

## Что уже входит в каркас

1. Установщик и деинсталлятор модуля.
2. Проверка минимальной версии PHP и обязательных модулей Bitrix.
3. Явная регистрация классов пространства имён `Otus\Autoservice`.
4. Централизованный реестр обработчиков событий.
5. Страница настроек модуля.
6. Административная страница состояния окружения.
7. Русская локализация интерфейса и установщика.
8. Безопасное удаление с отдельным выбором сохранения данных и настроек.
9. Реестр версионируемых миграций с последовательным применением и обратным откатом.

Каркас пока не создаёт таблицы, пользовательские поля CRM и бизнес-сущности. Это будет выполняться отдельными версионируемыми миграциями после согласования модели данных.

## Важные ограничения

Установщик намеренно не создаёт и не изменяет автоматически:

- пользователей;
- структуру компании и подразделения;
- группы пользователей;
- роли и права CRM;
- назначения сотрудников на воронки.

Эти настройки переносятся между окружениями отдельным сценарием конфигурации и требуют явного запуска администратора. Отмена автоматического создания оргструктуры зафиксирована в проектном плане.

Для контроля незакрытых заказов отдельная таблица блокировок не используется. Проверка будет выполняться по сделкам сервисной воронки: идентификатор автомобиля плюс незавершённая стадия.

## Зависимости

- PHP `7.4.0` или новее;
- `main`;
- `crm`;
- `catalog`;
- `pull`;
- `rest`;
- `im`;
- `bizproc`.

При отсутствии обязательной зависимости установщик остановится до регистрации модуля.

## Установка

1. Разместить каталог в `local/modules/otus.autoservice`.
2. Открыть административный раздел Битрикс.
3. Перейти в список установленных решений.
4. Найти «Автосервис OTUS» и запустить установку.
5. После установки открыть «Сервисы → Автосервис OTUS → Состояние модуля».
6. Проверить зависимости и затем сохранить основные настройки.

Предварительную проверку версии PHP и наличия исходников зависимостей можно выполнить из консоли:

```powershell
php local/modules/otus.autoservice/tools/check_requirements.php
```

Если корень сайта не определяется автоматически, передать его первым аргументом.

## Удаление

При удалении флажок сохранения данных включён по умолчанию. В этом режиме удаляются регистрация модуля, обработчики и скопированные административные файлы, но сохраняются настройки и будущие прикладные данные.

Если снять флажок, установщик также удалит настройки модуля. Удаление будущих таблиц и пользовательских полей должно быть реализовано миграциями с такой же проверкой параметра `save_data`.
